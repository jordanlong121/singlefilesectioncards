# Trail Buddy — app brainstorm

One note, one brainstorm. Every H3 below becomes a sticky note on the card wall.

### 🌟 The big idea

A hiking companion app that works **fully offline**: maps, safety check-ins,
and trail notes that sync when you're back in range.

Pitch in one line: *"Your trail journal, safety net, and map — no signal required."*

### Audience

- [ ] weekend day-hikers (largest group)
- [ ] multi-day backpackers
- [ ] trail-running clubs
- [ ] search & rescue volunteers?

### Feature ideas

- [ ] offline topo maps with #core routes
- [ ] "I'm OK" check-in via satellite SMS #safety
	- [ ] auto-notify a contact if overdue
- [ ] photo waypoints pinned to the track #journal
- [ ] gear checklist per trail type
- [ ] share a trip plan as a link #social

### Wild ideas

No idea is too weird in this card.

- [ ] AR peak identification
- [ ] leech warnings by region
- [ ] mesh networking between hikers' phones

### Open questions

- [ ] buy map data or use OpenStreetMap?
- [ ] battery budget for GPS tracking?
- [ ] what does SAR actually need? ask [[Field Log]]

### Risks

- App stores are full of map apps — differentiation is #safety, not maps
- Satellite SMS needs hardware partnerships
- Offline-first sync is genuinely hard
